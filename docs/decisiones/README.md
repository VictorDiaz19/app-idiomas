# Decisiones de arquitectura (ADR)

Cada decisión importante del proyecto se registra aquí en un archivo Markdown
corto y numerado: `0001-titulo.md`, `0002-titulo.md`, ...

## Plantilla

```markdown
# NNNN. Título de la decisión

- **Estado:** Propuesta | Aceptada | Reemplazada por NNNN
- **Fecha:** AAAA-MM-DD

## Contexto
¿Qué problema o situación nos obliga a decidir?

## Decisión
¿Qué decidimos?

## Consecuencias
¿Qué ganamos, qué perdemos y qué cambia a partir de ahora?
```
